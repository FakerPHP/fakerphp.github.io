# Company

## company

Generate a company name.

```php
echo $faker->company();

// 'Upton, Cormier and Schaefer'
// 'Nikolaus-Klein'

```

## companySuffix

Generate a company suffix.

```php
echo $faker->companySuffix();

// 'Group'
// 'PLC'

```

## jobTitle

Generate a job title.

```php
echo $faker->jobTitle();

// 'Electronic Engineering Technician'
// 'Barber'

```
